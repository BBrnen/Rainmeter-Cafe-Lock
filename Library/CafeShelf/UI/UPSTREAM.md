# ShelfSuite integrated configurator

Adapted from MartinSantosT/ShelfSuite v2.1, commit d4f186ba0b5c262c7559b80841132f5fd3884f3c, `Shelf Suite/@Resources/configurator.html` (Git blob 4d7692def82a5913c36b108387fcd4c45867059f). MIT copyright (c) 2025 Martin Santos; see LICENSE-ShelfSuite.txt.

Retains the configurator's styles, shelves/sidebar, tabs, item fields and dialog layout. Scripts and markup are adapted to safe DOM operations, native file selection and asynchronous native saves. Direct File System Access, lossy Lua rewriting, remote updates and inline handlers are removed. Existing installed skin/engine files and the pinned version remain unchanged. PNG previews come from the same native bytes committed to Icons. No page filesystem API is available.
