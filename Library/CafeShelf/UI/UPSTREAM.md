# ShelfSuite editor asset provenance

The final configurator adaptation targets ShelfSuite v2.1 at
d4f186ba0b5c262c7559b80841132f5fd3884f3c without changing the installed skin.

Current files are original Cafe Lock host/selection preview assets, not yet
the adapted upstream configurator. No upstream HTML has been copied here.
The later configurator UI task must record the original source file SHA,
retain its MIT license and adapt the approved existing interface.

Assets are embedded in Rainmeter.dll and served only by the guarded native
host. Installed skin HTML never receives the native bridge.
